WORD CARDS — личные карточки для английского на iPhone

Внутри:
- index.html — структура экранов приложения;
- styles.css — оформление;
- app.js — добавление, карточки, темы, прогресс и повторение;
- manifest.json и sw.js — параметры установки и офлайн-кэш.

Установка на iPhone:
1. Этот ZIP — исходные файлы, а не готовый .ipa-файл App Store.
2. Нужно опубликовать файлы на HTTPS-хостинге. Самый простой путь — GitHub Pages.
3. Создай репозиторий на GitHub и загрузи в его корень файлы из архива.
4. В репозитории: Settings → Pages → Deploy from a branch → ветка main → /(root) → Save.
5. Когда GitHub Pages покажет опубликованный адрес, открой его в Safari на iPhone.
6. Нажми «Поделиться» → «На экран Домой» → «Добавить».
7. Открой значок приложения с главного экрана. Сначала нужен интернет для загрузки и кэширования файлов.

Важно:
- Слова и прогресс сохраняются в локальной базе Safari на этом iPhone.
- Данные не синхронизируются автоматически между устройствами.
- Во вкладке «Мои слова» можно экспортировать JSON-копию и позже импортировать её.
- Не очищай данные сайта, не сохранив резервную копию.
- Это личное веб-приложение, а не нативный iOS-пакет .ipa и не публикация в App Store.
